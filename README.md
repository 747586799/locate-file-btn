# 定位当前文件 (Locate Current File)

这是一个简单而实用的 VS Code 插件，旨在优化资源管理器的文件导航体验。

## 核心痛点

VS Code 默认的 `explorer.autoReveal`（自动定位）功能会在你切换标签页时，自动在左侧资源管理器中滚动并选中当前文件。
- **缺点**：当你在查看多个文件或浏览长列表时，资源管理器频繁跳动会让人感到眼花缭乱，甚至丢失原本浏览的上下文位置。
- **解决**：如果你关闭了 `autoReveal`，当你真正想找到当前文件在哪个文件夹时，又需要手动去一级级展开，非常麻烦。

**这个插件完美解决了这个问题：它让你保持“自动定位”关闭，仅在需要时点击按钮一键定位。**

## 功能特性 (Features)

1.  **手动定位按钮**：
    在资源管理器（Explorer）的标题栏添加一个“定位图标” (🎯)。点击它，左侧文件树会自动展开并滚动到当前正在编辑的文件。

2.  **自动优化设置**：
    插件启动时，会自动检测并**关闭** VS Code 原生的 `explorer.autoReveal` 设置。
    *   *效果*：切换文件时，资源管理器不再乱跳。
    *   *提示*：当你真正需要定位文件时，点击我们的按钮即可。

## 使用方法 (Usage)

1.  打开任意文件进行编辑。
2.  将鼠标移动到左侧“资源管理器”的标题栏位置（通常显示为项目名称或“文件夹”字样）。
3.  点击出现的 **“定位当前文件”** 图标（类似准星/靶心的图标）。
4.  资源管理器将自动展开路径并高亮当前文件。

## 插件设置 (Extension Settings)

本插件会自动修改以下 VS Code 全局配置，以达到最佳体验：

*   `explorer.autoReveal`: 设置为 `false` (关闭自动定位)

> **注意**：如果你手动重新开启了 `autoReveal`，下次重载窗口或启动插件时，为了保证插件的核心体验，它可能会再次被设置为 false。
